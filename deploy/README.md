# Развёртывание на psr.rascroi.ru (nginx + systemd)

Приложение подетального учёта на поддомене `https://psr.rascroi.ru`. Настоящий
сертификат Let's Encrypt снимает все проблемы с камерой (Android + Chrome).
Схема: nginx терминирует HTTPS и проксирует на Flask `127.0.0.1:5001` (режим
`--http`, самоподписанный сертификат не нужен).

## Шаги

1. **DNS.** A-запись `psr.rascroi.ru` → IP VPS. Дождаться распространения.

2. **Код и окружение.**
   ```bash
   sudo mkdir -p /opt/psr && sudo chown $USER /opt/psr
   git clone <repo> /opt/psr && cd /opt/psr
   python3 -m venv .venv
   .venv/bin/pip install -r requirements.txt
   ```

3. **Служба** (`deploy/psr.service`): скопировать в `/etc/systemd/system/`,
   выставить `User`, `DA_ADMIN_PIN`, `DA_FTP_PASS`, затем
   `sudo systemctl daemon-reload && sudo systemctl enable --now psr`.

4. **nginx** (`deploy/nginx-psr.conf`): установить по инструкции в шапке файла,
   создать пароль `htpasswd`, затем `certbot --nginx -d psr.rascroi.ru`.

5. **Файрвол:** открыть 80/443; порт 5001 — только localhost.

6. **Проверка:** открыть `https://psr.rascroi.ru` — сертификат валиден, `/admin`
   просит PIN; с телефона Android+Chrome камера включается без предупреждений.

## Данные (важно)

FTP развёрнут **на этом же VPS**, поэтому FTP-протокол приложению не нужен —
оно читает папку FTP как локальный путь. Это основной, самый простой способ:

1. Определить папку, куда FTP складывает файлы (напр. домашняя папка
   FTP-пользователя `/home/ftp1c/` или `/srv/ftp/psr/`).
2. Дать процессу приложения (`User=psr` в службе) **право на чтение** этой
   папки — общая группа или ACL:
   ```bash
   sudo usermod -aG ftp1c psr          # пример: psr в группу FTP-пользователя
   sudo chmod -R g+rX /home/ftp1c/
   ```
3. 1С и Базис кладут в эту папку: `производственные операции New_1 (XLSX).xlsx`
   и файлы `.xbir`.
4. В админке → «Настройки путей»:
   - `one_c_plan` = `/home/ftp1c/производственные операции New_1 (XLSX).xlsx`
   - `basis_xbir` = `/home/ftp1c/` (или подпапка с `.xbir`)
5. Нажать «Связать и импортировать». Всё.

FTP-кнопка «Забрать выгрузку 1С с FTP» и переменная `DA_FTP_PASS` при этом
**не нужны** — они остаются как запасной вариант на случай, если источник
переедет на **другой** хост.

Альтернатива для разовых файлов — загрузка через админку из браузера.

Логи станков на упаковочном пилоте не нужны; для продакшна — отдельный
агент-пушер (отдельное ТЗ).
